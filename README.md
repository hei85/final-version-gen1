# 最终版本第一代 · 销售分发版

衍图便携工作站的干净销售分发版。程序、插件、技能、运行环境和本地模型能力与最终版本第一代一致；不包含原用户的账号、数据库、素材、项目、API Key、日志或本机状态。

## 客户拿到后的效果

- 首次启动自动初始化全新本地数据库
- 免登录直接进入工作台
- 模型列表中不包含任何上一位用户的渠道和密钥
- 客户可自行添加自己的模型 API 服务与密钥
- 启动方式与本地版完全相同
- 支持可选的 Codex 衍图插件安装

## 安装

1. 将三个分卷放在同一目录。
2. 从第一卷开始解压：

```powershell
7z x .\yingce-final-version-gen1-clean.7z.001 -oD:\衍图
```

3. 进入解压目录：

```text
D:\衍图\衍图便携版
```

4. 双击：

```text
启动衍图.cmd
```

5. 浏览器打开 <http://localhost:3000>，首次启动会创建全新的空数据库。

## 安装到 Codex（可选）

如果需要 Codex 操作画布，运行：

```text
安装到Codex.cmd
```

然后新开一个 Codex 对话，让插件和 MCP 重新加载。

## 模型配置

本包不包含任何原用户 API Key。客户需要在：

```text
设置 → 模型设置 → 添加模型
```

填写自己的 Base URL、API Key、模型 ID 和参数。
