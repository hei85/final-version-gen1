# 整片制作入口

固定启动口令为“@衍图 + Agent全自动制作”，允许“Agent 全自动制作”的空格写法。用户表达实际制作意图时，按已有整片流程执行；只讨论、展示或设置口令时不启动制作。这个入口只路由至既有规则，不替代或改写规则，不额外扩大模型、并发或费用授权。

用户要求从剧本制作、继续或修复整片时，必须读取 [衍图整片制作](../yingce-film-production/SKILL.md) 的完整入口及其执行合同。提示词写入原生生成文本框，图片使用真实智能 @；本阶段所有必需产物自检通过后才能下一步，由 Agent 持续执行到实际成片。按当前 MCP 工具、渠道能力和持久运行接续，复用通过素材；规则复盘不启动旧片返工。
