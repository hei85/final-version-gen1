# MCP画布制作规则（当前执行版）

版本1.6.7。执行前先完整读取[布局与单次切图规范](canvas-layout-and-split.md)、[Agent执行合同](portable-agent-workflow.md)与[AI视觉复查门](visual-review-gate.md)。本文件替换历史逐日追加的执行指令；历史案例已保存为归档供追溯，不能作为当前项目命令。

## 唯一工作流

1. 读取用户剧本、当前画布、真实任务、采用资源、项目规格与授权。
2. 拆解全部角色、场景、道具、准确对白、关键动作与时间。封闭室内按[固定空间三步流程](fixed-space-workflow.md)先房型、同一模型、固定机位；户外使用环境参考。
3. 生成或复用全部独立人物、场景和道具，按[单张人物设定图](character-sheet-and-key-states.md)实际审看后采用。每角色是一张正/侧/背全身（将脸部强模糊至五官不可识别、保留头部发型）＋唯一正脸特写，不能改成两张独立资产或对人物设定做剧情四格分割。门等道具只包含物件；已做好的台灯等道具必须真实绑定到需要它的图，不只是提示词写名字。
4. 先按[换视角与时长连续性](shot-camera-continuity.md)排逐镜长度与相邻不同机位，再为本镜唯一四宫格设计四个有关键内容的状态及连续时间范围；逐格写叙事/动作/情绪作用，近似姿势凑数不能通过。每镜固定机位或连续运镜；前镜末格传状态，本镜首格在新角度提供新信息，允许保持同一站位，不复刻构图、不强制新走位。
5. 先实际 AI 审查母图四格，逐格对照身份图、检查身体数量、手指及持物并复查；任何格失败或看不清就修复重审，全部通过才原生分割一次。必要时仅裁真实分隔残边，逐图审看后立即替换并清理临时图。每镜最终只展示1母图+4切图，真实来源线完整。
6. 全片图片完成后，逐镜绑定真实四图及必要身份、场景/衔接参考，核对智能@、编号、面板、连线、首帧和实际请求。参考数量与模型参数以当前渠道能力为准。
7. 规划声音和带时间分镜粗剪，锁定镜头、时长、采用版本。样片设计必须允许按前镜实际出口顺序检验，不能把依赖尚未生成的非样片镜头的连续性列为无法满足的样片完成条件。
8. 使用正式运行生成、查询原任务、完整解码和逐镜看图听音。MiniMax H3使用官方对应指南及本地适配；按输入模式使用中文正文（全参考六段、基础模式三字段），真实引用放在相关动作段，原句中段完整说完。
9. 剪辑合格片段与全部必要过渡；按最新用户要求处理无用镜头及不合适声音，准确对白和有效环境声保留。实际导出和整片检查后交付。

每阶段必需产物全部可读、内容检查通过、绑定及版本正确才完成。未知、运行中、失败、未审不能冒充passed。独立候选可按当前授权并发，正式采用与有前镜依赖的镜头顺序执行；画布写入始终用fresh revision串行。当前会话不使用子代理，历史并发和模型分工不继承。

## 逐项内容审核

读取[图片提示词与检查](image-prompting-quality.md)、[空间距离](spatial-distance-continuity.md)、[跨镜衔接](video-continuity.md)、[对白与声音](voices-dialogue.md)与[自检工作流](self-check-workflow.md)。

- 每张基础图、每个母图格、每张切图分别审看原像素；记录身份、服装、可见左右手和下肢、脸部/反射、道具形态数量与握法、相机轴线、门窗家具和光源、动作差异以及四边。
- 景别裁切、真实遮挡、背面正常可出画；画内畸形、粘连、涂抹或消失不以恐怖气氛解释。物理间距按共同模型与路线记录，投影变化不是房间变大。反射人物同样检查。
- 固定家具及道具守恒；透明杯不换材质，持物左右手不互换，人物不能因多图参考复制实体；跨门路线和实际过渡进入时间线。
- 失败台账累计真实资源、格子/时刻、问题、正确目标及下一版验证项。新版只用已合格基础资产与有效前镜状态，保留正确部分，不用失败母图引导；反复问题评估局部修改或剪辑，不盲目堆否定词重复收费。
- 技术解码、视觉审核、ASR和听审分开。没听到音轨不得声称音质、声线或口型通过。任务成功和阅读技能回执均不能代替质量检查。
- 回执未知先查原任务/操作；明确终止且无有效结果才在授权内建立retryOf的新尝试。旧任务不能覆盖采用版。删除无用失败候选前核对引用与运行任务，保留证据。

## 排版收尾

采用[布局与单次切图规范](canvas-layout-and-split.md)中的唯一项目合同。当前图片卡片统一480×270等比完整显示，区域明确、镜号顺序、四图2×2、来源线完整。绑定和分组完成后才作最后一次尺寸与位置整理；父组先移动，子节点后定位；回读实际矩形和parentId再登记通过。不得以重切图片修排版。

每批创建、切分、绑定及替换后自动执行以上收尾，不等用户提醒。新项目由 Agent 规划并维护全部制作分区；已有项目只整理受影响区域，保留其他手工布局。
