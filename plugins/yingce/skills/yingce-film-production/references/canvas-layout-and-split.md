# 画布布局与单次切图执行规范

版本：1.6.8，2026-10-12。此文件是布局、切图、替换与清理的唯一当前执行规则。用户最新要求优先；历史单片参数只留在制作台账或归档，不作为当前命令。

## 1. 决策优先级

当前用户要求 → 本项目已锁定的规格与采用版本 → 当前渠道的真实能力 → 本规范 → 其他通用指南。发现矛盾时先改成一份明确合同，再操作；不一边保留旧尺寸或旧并发，一边追加相反规则。当前会话不使用子代理。其他项目是否委派由其用户与上层指令决定，历史委派要求不跨项目继承。

人物设定与剧情四格分别按[单张人物设定图与关键内容](character-sheet-and-key-states.md)执行：三视图将脸部强模糊至五官不可识别＋唯一正脸同在一张人物图，不拆成四张人物资产；每个叙事镜头只采用一个含四个关键时刻的母图，不能多做一套“关键帧四宫格”。人物参考和剧情母图在对应区域排列，完整显示，不能为了统一卡片裁掉人物或正脸。

## 2. 只切一次，始终只有一套采用切图

| 状态 | 允许的下一动作 | 禁止的动作 |
| --- | --- | --- |
| 母图没有通过逐格检查 | 检查或修复母图 | 切图、绑定视频 |
| 本母图资源版本没有切图记录 | 原生切成1、2、3、4，立即保存实际返回ID | 从同母图创建第二套四图 |
| 原切图已有无边满画面 | 逐张检查后直接采用 | 为了流程再次裁边或再次宫格切分 |
| 切图有实际分格残边 | 仅处理对应图片的边，保存派生资源 | 重跑母图分割、重生整张合格母图 |
| 派生图片已审看通过 | 优先原生替换原切图节点的媒体，再删除派生临时节点；工具只能输出新节点时，立即替换引用并删除原临时节点 | 把原4张与去边4张长期并排展示，等下一阶段才清理 |
| 回执不明或接续 | 查原操作、节点、资源与持久结果，恢复真实记录 | 把未知结果当作没切过而重放脚本 |

切图登记键必须包含母图resourceId及采用版本。每镜恰好四张不同的最终采用图片，顺序为左上、右上、左下、右下；切边识别实际分隔，检查邻格残留及必要部位误裁，不补白、不拉伸。新母图版本确有返工时只为新版本切一次，旧版从画布清掉，失败证据仍保存。

清理之前确认替换资源已保存、可解码、逐张审看且所有采用引用已迁移；运行中任务或仍有用途的身份、空间、道具图不得误删。来源资源保存在台账，不要求把两套节点同时放在画布。

## 3. 来源、名称与真实引用

母图到最终四图保留可见来源线；每图保存sourceMotherNodeId、sourceMotherResourceId、cellOrder及派生处理，不能只连到已删除的临时图。

- 母图：镜头NN｜剧情名·四阶段母图。
- 切图：镜头NN·阶段1—4｜状态名。
- 分组：镜头NN｜剧情名·最终独立分镜。
- 视频：镜头NN｜剧情名·待生成/运行中/待审/采用状态。

原生生成、分组、绑定或替换重置名称时立即恢复并回读。提示词只写在生成面板，不创建独立提示词文字卡；分区名称用真实容器标题。智能@、分镜绑定、可见引用与真实输入按资源去重且顺序一致。来源线描述派生，不能把母图当视频参考。视频首帧是本镜最终切图1；前镜末格只作连续状态参考，不复制成后镜首格。参考数量、严格尾帧等按本渠道能力，不固化旧片六图上限。

## 4. 清楚分区与统一卡片

按剧本/空间规划 → 独立人物道具 → 共用模型机位 → 写实场景 → 有序分镜表 → 每镜母图 → 本镜四张独立图 → 对应视频 → 后期交付组织。空间规划只在封闭室内要求房型、共用模型、机位三步，户外不强制建模。

每个区域有唯一清楚的容器标题、用途与节点列表。人物和道具分开命名，结构图与写实场景分开，母图与独立切图区分。镜头从上到下依NN顺序，每镜四图排2×2，读法固定；视频与该镜同一横行。四张图是时间状态，不是四个房间或四个人。

同一项目统一所有图片卡片的显示宽高。当前画布合同为480×270；这只改变画布展示，不裁掉原图、修改像素或重生素材。竖版道具、平面图及其他比例采用完整等比contain显示，设置manualSize=true、freeResize=false；freeResize=true会拉伸图片，不能用于统一卡片。软件媒体最小框为420×236，布局尺寸不得低于这个值，避免保存时自动放大。

图片水平间距至少48，垂直间距至少48；当前同类网格水平64，镜头行距780。容器顶部预留标题与60以上内容区，边界留24以上。按真实矩形计算，不能只看目标坐标。文档/分镜表可按阅读需要单独定尺寸，不属于统一图片卡片。用户另定尺寸时更新一份项目合同，所有脚本读取同一合同，不在脚本中另写330/550等旧值。

## 5. 原生操作后的固定收尾顺序

1. 读取真实画布、采用资源、原任务与最新revision/stateHash；复用既有图，不为整理生成素材。
2. 完成分镜绑定、原生分组和视频节点复用；这些操作可能改名称、尺寸或位置。
3. 把节点放进对应容器，恢复标题与manualSize，统一卡片及容器尺寸。
4. 先移动父容器，再单独定位子节点；禁止同一批同时移动父与子造成二次位移。
5. 回读实际所有宽高、位置、parentId、名称、采用resourceId、来源线与引用。验收不通过只修排版；不能重切或重生媒体。
6. 保存真实验收记录并截取实际画布。区域边界/标题没有遮挡、同类卡片均匀、四图数量正确、参考保持后再推进。

## 6. 当前验收必须覆盖

实际全部图片卡片同宽同高且等比显示；每个非框节点属于明确区域并完整位于框内；同层图片/文档/视频无重叠，区域框之间无重叠；所有镜头按序；每镜只有一张采用母图和四张最终切图；每张母图到其最终四张切图的来源线齐全（总数为4×采用母图数量，不固定24条）；采用资源与整理前一致；无失名、重复切图、删错采用图或新增收费任务。空的视频输出区域要明确标待生成，不能假装已有视频。
