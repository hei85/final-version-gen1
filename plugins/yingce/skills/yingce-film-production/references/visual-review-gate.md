# 图片与视频的 AI 视觉复查门

版本：1.6.8，2026-10-12。用于后续剧本制作的资产、四宫格、独立切图和视频验收。用户只要求更新规则或已确认本片结束时，不重新检查或返工本片。

## 1. 先审查真实画面，再进入下一步

检查者必须实际收到并查看当前资源的图像：具有视觉输入的 Agent 可以直接审查，也可以使用已接入的视觉模型。只有文本输入的模型、解码结果、提示词分析、任务成功、审美评分不能完成本项。工具报告只覆盖它实际检查的范围。

基础人物、场景、道具逐资源审查。四宫格先查看整张原图，再分别放大左上、右上、左下、右下，逐格对照采用身份图、场景、道具和本格预期动作。手与脸较小时，查看足够清楚的局部；局部放大只用于检查，不创建第二套画布切图。不能用整张缩略图、第一格正常或笼统的“整体合格”代替四格记录。

母图四格全部通过才允许原生分割一次。切分后四张独立图再分别检查内容与切边；母图通过不自动使切图通过。全片本轮必需图片及真实绑定全部通过，才进入视频阶段。先做一镜试验也不能跳过该镜所需图片审查。

人物基础图先按[单张设定图规范](character-sheet-and-key-states.md)核对：同一张图只有正/侧/背三张完整全身和一个正脸特写；全身三视图脸部强模糊至五官不可识别，但头部/发型/头颈连接正常。正/侧全身脸需放大确认五官不可识别，不能以轻微失焦放行；唯一正脸特写必须保持清晰，不能谎称模糊图已核对完整脸；唯一正脸实际查五官、年龄感及发型。三视图不是三个角色，正脸特写不是多余人物。剧情格则必须正常有脸并与这个唯一正脸一致，不能继承脸部强模糊处理。

母图审查还须确认每镜唯一采用版本和每格的关键内容、剧情/动作/情绪作用：四个阶段均有可见依据，近似重复凑格或关键内容没实现即失败。人物设定图不进行剧情四格切分。

## 2. 每格必须核对的项目

| 项目 | 实际检查与失败条件 |
| --- | --- |
| 人脸与身份 | 对照人物设定图唯一正脸特写和同母图其他格，核对年龄、脸型、五官关系、发型、肤色与服装。角度、表情、光照可以变化，不能换脸、换人、重复五官或脸部融化。镜面倒影也要查；背面或真实遮挡注明依据。 |
| 人数与身体连接 | 按剧本核对每格实际实体人数，分别追踪头颈、肩、躯干、上臂、前臂、手及髋膝腿脚。普通人不能长出第三只手、额外手臂、双重脸或断开的肢体；不同动作时刻不能复制成多个实体。剧情明确需要影子、倒影或非人形时按对应设定单独核对。 |
| 可见左右手与手指 | 逐只可见手检查是否连接到正确手腕、关节方向是否合理、是否多指/粘连/缺失/变成肉块，左右手是否与动作连续。普通完全展开的手通常五指；握拳、持物、出画或遮挡不能强迫显示五指，也不能借“遮挡”掩盖实际多手或不连贯结构。 |
| 持物与接触 | 手机、工具、杯子等实体数量、形态和持握关系正确；手指围绕物体自然，物体不穿掌、不悬空、不与身体融合。持物手改变要有实际动作，不能因换机位直接互换。 |
| 动作与四格区别 | 四格都有计划的关键内容和具体剧情/动作/情绪作用，不能只有相似姿势；同一关键事件可覆盖重要阶段，不硬添四个事件。四格按本镜时间状态推进，动作可实现，人物身体朝向、头部、视线、重心与道具状态分别合理。不能复制同一格凑数，也不能把前镜末格完整复刻成本镜首格。 |
| 换视角与跨镜状态 | 按[相邻镜头换视角](shot-camera-continuity.md)比较前镜末态与本镜首格：新机位实际有可见区别，演员站位、轴线、视线、左右手和动作阶段接续。人物可以在新角度继续站定；同角度推近、只改cameraId、人物瞬移或重做已完成动作均不算通过。每镜四格保持固定机位或规划连续轨迹，不随机切四个角度。 |
| 场景与空间 | 对照采用场景和封闭空间的共享模型、对应机位，门窗、床桌、光源、固定道具及相对位置保持。景别改变只改变投影；物理距离变化须有实际走位。 |
| 清晰度与图面 | 必须看清叙事主体及需要检查的手、脸；无融化、重影、局部涂抹、邻格内容或错误剧情文字。字幕策略按用户要求；手机短信等剧情文字单独核对原句。 |

画外、背面和真实遮挡可记录为不适用并说明可见依据，不能写成已看见且通过。应可见但无法判断的部位记 uncertain；回读高清原图或局部后仍不清楚，就作为待修项，不能放行。恐怖、悬疑气氛不是多余肢体或身份漂移的合格理由。

## 3. 留下逐格证据，补查易漏部位

检查记录绑定实际 resourceId、资源版本或文件哈希、采用身份/场景/道具参考、镜号、格号或视频时刻、实际评估者及检查时间。每项写 passed / failed / uncertain，并写具体可见现象；不适用项说明遮挡或出画依据。记录传入当前接口时使用真实 schema，不发明服务器已支持的字段。

每张四宫格有四条格子记录；每张独立切图有自己的记录。不能把同一段模板结论复制四次。通过前再复查一次身份、身体数量、手指与持物，逐格与身份锚点和相邻状态比较；初审看不清的区域必须在这次解决。复查未完成就保持待审。

`film_self_check` 负责列出资源、缺项和过期证据，Agent 的真实视觉审查负责内容判断。向 `film_record_step_result` 写入 reviewedMedia 时，逐资源 checks 的 observation 必须涵盖上述身份、身体、手部、道具及四格检查结果；母图观察注明格1—4。任何已发现的 failed 都不能被技术解码或另一份笼统 passed 覆盖。

## 4. 不合格就修复、重新审查

1. 记录失败资源、格子/区域或时间区间、症状、正确目标与实际原因证据；原因不明就注明。失败图不得作为首帧、动作参考或下一镜承接。
2. 局部手部错误且身份、空间正确时，在现有授权和真实工具能力内局部修图；身份或多格结构明显错误时，改清提示词和参考关系后重新生成本镜母图。其他合格资产不重生。
3. 只有确认原请求已终止、无未知付费任务时才提交新尝试，保留 attempt/retryOf。运行中只查询原任务，不能把预览空白当作失败重发。
4. 修复输出视为新的未审资源，重新审查全部受影响格子、母图各格的身份/空间关系及后续切图。旧版通过记录不能沿用到新版本。
5. 新母图版本通过后只切一次，迁移首帧、关联、智能 @ 和来源线，核对引用后清掉被替代的画布候选。仅修排版不切图、不生图。
6. 同类缺陷反复出现时，换更明确的参考、局部修复方法或可行镜头设计；不盲目重发相同提示词。无可行修复或缺少实际审查能力时保留阻断状态，说明具体缺口。

## 5. 视频再查，画布自动整理

图片合格不代表视频合格。视频完整解码后，查看实际首末帧、动作前中后、说话期间和相邻镜头；手部、持物、转身、反射等高风险区间增加抽帧或逐帧检查。身份、额外肢体、人物复制、道具跳变、动作顺序、空间和衔接失败均返修重审；相邻镜头还须实际确认新视角及动作匹配，旧角度重复而未明确要求延长时不能通过。声音与口型仍按 [自检工作流](self-check-workflow.md) 实际检查，视觉通过不能代替听审。

每批创建、切图、绑定或替换完成后，Agent 主动按 [布局与单次切图规范](canvas-layout-and-split.md) 整理受影响区域，无需等待用户再次提出。新项目先建清楚分区；镜号按序、同类图片卡片统一尺寸且等比完整显示、每镜四图2×2、母图来源线和图→分镜→视频路径完整、名称可读、无重叠并留间隔。先移动父容器再定位子节点，最后回读实际矩形、标题、parentId 和资源；排版未完成不登记该批完成。

复盘依据：用户指出《凌晨三点的敲门声》第一镜四宫格存在不同格人脸不一致和多余手/手臂，之前未拦下，属于漏审。本规则用于后续项目；不补写当前已结束作品的通过结论，也不重新生成本片。
