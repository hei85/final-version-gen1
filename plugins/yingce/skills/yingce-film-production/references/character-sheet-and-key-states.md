# 人物单张设定图与每镜四个关键画面

版本：1.6.8，2026-10-12。采用用户最后一次纠正：**三视图加一个正脸，生成在同一张图；三视图里的全身人物将脸部强模糊至五官不可识别，只有一个正脸特写。**此前“独立头像＋独立三视图”解释已撤销。适用于以后新剧本；不重新生成或改写用户已完成影片。

## 1. 人物资产：一张图，两种参考用途

每个角色的当前服装版本采用一张人物设定图，包含下列四个展示区域；这不是一个剧情镜头，也不是四个时间阶段。

| 展示区域 | 内容 | 用途与限制 |
| --- | --- | --- |
| 正面全身 | 头顶到脚完整，体型、服装、鞋和配饰清楚 | 保留正常头部、发型与头颈连接，脸内部强高斯模糊至五官不可识别，不另画清晰可辨识的脸 |
| 侧面全身 | 同一体型、服装与发型的侧面 | 保留头部外轮廓和发型，脸内部强高斯模糊至五官不可识别，不增加侧脸头像 |
| 背面全身 | 同一人的背面，后脑、服装后片和鞋清楚 | 正常后脑和发型，不增加背面头像或额外脸 |
| 唯一正脸特写 | 同一角色的清晰正面头部，可包含少量肩颈 | 唯一完整脸部身份锚点，五官、脸型、年龄感和发型清楚；不拼侧脸、表情合集或第二个正脸 |

**默认保留正常头部，只模糊全身参考的脸内部。**正面和侧面全身脸必须明显模糊，放大后眼、眉、鼻、嘴均不可识别；轻微失焦但仍可读出五官不合格。保留头发、外轮廓、耳朵与正常头颈，背面后脑保持正常。用户明确允许去头时可采用其指定的无头身体参考方案，但不能把颈部断口、畸形或丢失身体当作通过；同图唯一清晰正脸特写仍保留。实际剧情图片与视频中的人物必须有正常脸部，根据设定图唯一正脸生成，不能继承全身参考的脸部强模糊处理。

人物设定图风格服从本片：漫剧使用锁定的漫剧风格，写实片使用对应写实外观。三个全身展示同一人、同一身高比例、服装版本、发型和配饰。正脸特写中的年龄、肤色、发型与全身相符。身体摆放和正脸特写各有清楚区域；不强制人物设定图采用剧情2×2，也不把三个全身头像额外裁出拼回图里。

已有符合本规范的采用设定图直接复用。只有新制作确有缺项或当前候选不合格才在授权内修复/生成；不能因发布新规则自动重做旧片。换服装保留同一正脸身份，只为需要的新服装版本准备相应设定图，不借换装另造一张脸。

### 提示词模板与复检

输出一张人物设定图：左侧正面、侧面、背面三个完整全身，右侧唯一清晰正脸特写。仅正面和侧面全身的脸内部施加强高斯模糊，直到眼眉鼻嘴不可识别，保留头发、正常头部轮廓和头颈。背面后脑正常。右侧唯一正脸特写完整清晰、不可模糊，锁定同一人物身份。服装、身体比例、手脚和风格统一，不复制为多个角色，不增加头像。剧情图中的脸正常清晰，不继承全身参考的模糊。

局部修复明确哪些区域改变、哪些区域保留；使用实际蒙版和已有参考，禁止把“所有脸模糊”作为笼统提示。实际放大正/侧全身脸和唯一特写分别复检，轻度模糊仍露完整五官、误伤特写或新增清晰脸均失败。默认强模糊优先；是否去头服从用户当前指定方案，不由旧规则强行禁止已授权替代方式。

## 2. 真实引用与人物审查

1. 生成人物设定图时，已有合格身份来源就真实绑定它；提示词写在设定图生成面板。输出明确为**一张图**，完整说明三张全身将脸部强模糊至五官不可识别、唯一正脸特写画完整五官。不提交成四张独立图片。
2. 为角色登记这张图的实际节点、资源、版本/哈希、服装版本与审查记录。脸部和体型两种用途可指向同一资源，实际请求去重，只计一次输入。
3. 为场景关键图引用这张采用设定图，真实智能@内联说明：正脸特写约束五官身份，三视图只约束体型、发型、服装、配饰和前后结构；四个展示是同一人的资料，不是四个实体角色。剧情脸必须正常，不能用三视图的模糊面部作为脸部目标。
4. 审查时查看原图，放大唯一正脸与三张完整全身：确认正/侧/背各一个、仅一个完整正脸特写、无额外头部特写、无断头/多肢体，头部发型/身体比例/服装彼此一致。三视图将脸部强模糊至五官不可识别是设计要求，不对它伪报“已核对完整五官”；唯一正脸的五官必须实际检查。
5. 只为看清脸部而放大检查，不创建另一套画布资产，不把人物设定图送入剧情宫格分割工具。只有当前渠道确实要求专用单脸输入，才按其真实能力准备有来源的派生输入；不得静默替换用户的一张设定图交付规范，或把脸部强模糊的全身裁图当身份锚点。
6. 人物资产在人物参考区域按角色/服装版本排列，标题与单张资源对应。依照布局规范等比完整显示，缩略图大小不改变实际图片。绑定与排版完成后回读资源和输入用途。

## 3. 一个叙事镜头只采用一个剧情四宫格

按稳定镜号管理，每镜采用一张母图，左上→右上→左下→右下对应该视频的四个关键时刻。母图审查通过后只切一次，得到四张不同的采用切图；最终画布只展示本镜一张母图和这套四张切图，并保留来源线。

人物设定图的三个全身＋正脸不属于剧情四宫格。粗分镜阶段的文字/草图计划也不是第二张收费母图。不得按“先四宫格，再关键帧四宫格”做两套相同素材，不为换机位或整理排版重复生成、重复切割。

运行中或回执未知时查询原任务/操作。候选确有失败才建立有retryOf的新尝试；通过后只有新版本采用，旧失败候选和无用切图在引用迁移后从画布清理，证据保留。新的实际采用母图版本可切一次，不把“每镜一个”误读成不允许修复失败资源。

## 4. 四格都必须有关键内容，不能凑姿势

生图前写下本镜的叙事目的、时长、机位，以及每格：**代表时刻/时间范围、可见关键内容、它对剧情或表演的作用、与前格的变化、到下格的物理衔接。**这些内容进入实际生成提示词和分镜记录，不单独拉提示词文字卡。

| 合格的关键内容 | 不能替代它的填充内容 |
| --- | --- |
| 线索出现、读懂重要信息、威胁被察觉 | 四张只改变头部几度却没有新信息的近似画面 |
| 决定、情绪转折、明确反应、关系改变 | 无剧情依据随意摆四种表情 |
| 关键动作的准备、决定性接触/变化与后果 | 将同一姿态复制、只变裁切/滤镜或随便等分时间 |
| 关键道具/场景状态发生剧本要求的变化 | 加入剧本没有的动作、人物或事件来凑四格 |

四格可以覆盖同一关键事件的重要阶段，不要求凭空添加四个新事件。静止、迟疑或听声可以是关键状态，但必须有明确的情绪/信息/关系作用，不能只写“继续站着”。没有四个值得表现的状态时先重排本镜节拍、镜头范围或时长，保留用户剧情，不硬凑四格。

各格选择有剧情意义的时刻，不机械等分，不将用户15/10/15秒示例固化。四格共用固定机位或同一条规划好的连续摄影机路径，下一叙事镜头按[换视角规范](shot-camera-continuity.md)换角。重要内容在既定机位看不清时先调整可行机位/镜头计划，不能临时把四格画成四个任意角度。

按[AI视觉复查门](visual-review-gate.md)实际检查每格：

- 是否看得到本格计划的关键内容；是否有具体剧情/动作/情绪信息；与其他格近似重复是否只是凑数。
- 人脸是否符合设定图唯一正脸，衣服/体型是否符合三视图，剧情人物脸是否正常，实体人数是否符合剧本。
- 身体连接、可见手与手指、持物、空间、光线、动作顺序与跨镜状态是否正确。
- 逐格记录实际观察，再复查脸和手。任何格failed或uncertain均阻断母图采用、切割及视频；修复后重新审查，不能拿旧证据放行。

母图全通过才按[单次切图规范](canvas-layout-and-split.md)切成四张并再次审查。视频首帧是本镜采用切图1；四张切图按时间順序真实绑定，母图不作为视频输入。人物设定图是角色参考，不冒充其中某个剧情切图。视频再检验四个关键内容的实现和连续过渡，参考图/提示词文字本身不保证时间锁帧。

## 5. 规则来源与证据范围

“单张三视图将脸部强模糊至五官不可识别＋唯一正脸”和“每镜一个关键内容四宫格”是本用户当前采用的制作规范，不能宣称是所有模型公认的最新最优方法。MiniMax的[官方Subject Reference介绍](https://www.minimax.io/news/s2v-01-release)说明可由单张身份参考保持人物外观，但该介绍针对S2V-01，不证明本规范的具体排版、H3当前渠道能力或零缺陷。H3按官方技能和本次渠道实际合同执行；AI实际看图复查仍然必须保留。

补充来源：[Higgsfield 官方资产教程](https://higgsfield.ai/academy/courses/blockbuster-4k/stage-2-building-character-location-and-prop-assets)建议去除全身参考里的脸部细节并仅留一个脸部特写。本用户选择强模糊的具体做法；不是该教程对所有模型的保证。[OpenAI 图片提示词指南](https://developers.openai.com/api/docs/guides/image-prompting)支持明确编辑范围与保持项；当前具体模型仍按渠道合同执行并实际复查。
