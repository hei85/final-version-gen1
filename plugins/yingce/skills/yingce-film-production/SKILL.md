# 衍图整片制作

交付可播放的成片、可继续编辑的画布/时间线和真实任务记录。用大模型按剧情选择工具与模型，按缺口加载技能，不把创作变成固定镜头数或逐步确认表。

## 固定启动口令：只路由到既有完整流程

用户 @衍图 并明确要求“Agent全自动制作”或“Agent 全自动制作”时，即请求从剧本自动执行本技能已有的完整制作流程，终点为实际可播放成片及可编辑画布。“全自动做片”可按相同制作意图识别，Agent 大小写和词间空格不改变该意图。

先完整读取 [Agent执行合同](references/portable-agent-workflow.md)、[正式制作流程](references/formal-production-workflow.md)、[自动接续规则](references/agent-automation.md)，再按当前 phase 加载既有必读文件和检查合同；不能只读入口摘要就开始生成。已有剧本、素材、规格与授权直接沿用，常规创作、自检、返修与接续由 Agent 执行；只有缺少实际必需输入、能力或授权时说明具体缺口。

这个口令不替代或修改下列既有制作规则，不跳过阶段检查，不继承旧片的模型、费用或并发。用户只在讨论、引用、检查或设置口令时，仅处理入口或规则，不启动、恢复或返工影片。

## metaso 渠道的镜长与变速

仅在实际使用 **metaso 视频路线**时，按用户要求每镜尽量生成15秒，并逐镜规划1.5倍或2倍实际变速；15秒分别约为10秒或7.5秒，脚本、对白和总片长按变速后的采用长度预算。其他渠道不套用。详见 [metaso渠道节奏与时长](references/metaso-video-pacing.md)。

## 每次执行都必须落实的规则

切图、临时替换、分区、统一大小、父子移动及实际验收只按[布局与单次切图规范](references/canvas-layout-and-split.md)执行；该文件是唯一当前规范，不再并列执行历史尺寸或委派条目。

1. **提示词写在生成文本框。** 图片或视频提示词保存在真实目标节点的 prompt/composerContent；不单独建提示词文字卡、不拉文字到图片的提示词连线。剧本、规格、检查记录可放文档区；这也不是把提示词印进图像。
2. **图片用真实智能 @。** 每张参考绑定实际 nodeId/resourceId，内联放在它起作用的动作段。分镜关联、可见连线、缩略图、图片编号与实际请求输入一致；手打“@图片1”不能代替绑定。同一资源只传一次。
3. **每步完整完成再推进。** 为本阶段列全必需产物；全部生成或复用成功、资源可读取、逐项自检通过后，才登记完成并进入下一阶段。缺失、运行中、失败、未审或 uncertain 均阻断依赖步骤；同阶段独立任务可按当前授权并发。阶段检查由 Agent 执行，不要求用户逐镜指导。
4. **先资产，后关键图，再视频。** 独立人物、场景、道具先经实际 AI 视觉审查；按[AI视觉复查门](references/visual-review-gate.md)逐格对照身份图、检查身体数量、手指和持物并复查。母图四格全部通过才分割一次，四张切图再分别检查。失败或看不清就返修重审，不能进入下一步；全片所需图片与绑定全部通过后才生成视频。母图不能代替独立切图。
5. **首帧与衔接分开。** 首帧是本镜切图1；前镜采用末格只传递人物、空间、道具与动作状态，本镜首格按新机位独立设计，可以承接同一站位/动作阶段并提供新的镜头信息，不强迫演员移动。切图4是结束状态参考，严格尾帧只有当前渠道明确支持时才使用。参考数量按渠道核验，不套旧片六图上限。
6. **空间与内容检查真实落实。** 封闭室内先房型图、同一共享模型、登记机位及实测取景，再做图片和视频；户外不强制。换机位或焦段不能改变物理间距。视频成功不等于动作、台词和声音通过；真实看图、看视频、听音后分别记录，通过素材保留，仅修缺项和失败项。
7. **持续执行到真实交付。** 查询原 taskId，按持久运行接续；不把提交任务或写完剧本当作结束，不盲重发收费请求。合格片段与必要过渡进入真实时间线，按用户要求处理声音，完成实际导出和成片检查才交付。
8. **及时清理不用的图片和视频。** 替换、返工或阶段完成后，核对实际采用节点、分镜引用、首帧、时间线与运行任务；把已替代的失败图、重复媒体和无用候选从画布删除，不只移到远处。通过原生删除工具一并清理相关连线，回读确认采用媒体和引用仍完整。仍承担身份、道具、空间、机位或连续性参考的图不是冗余；运行中任务也不能因暂时无预览而删掉。失败原因和真实任务、资源 ID 保存到检查点，供下一版纠正。

开始制作先读 [可迁移的 Agent 执行合同](references/portable-agent-workflow.md)，文件路径为 `references/portable-agent-workflow.md`。它规定阶段清单、实际操作与回读条件。MCP `skill_prepare` 按当前 `phase` 使用 `agents/runtime.json` 的必读文件和工具清单；涉及特定模型、封闭空间或剪辑能力时再读对应指南。其余文件按任务细读，历史单片参数仅作追溯。

相邻叙事镜头的时长、机位差异、轴线、动作匹配、四格机位和实际复检统一按[相邻镜头换视角、时长与连续性](references/shot-camera-continuity.md)执行；规划、关键图、视频与切点复检时必读。15/10/15秒是用户三镜示例，合计40秒，不是所有影片的固定模板。

人物资产与四格关键内容统一按[单张人物设定图与每镜关键画面](references/character-sheet-and-key-states.md)执行，资产、分镜设计与复检时必读。人物是一张图中的正/侧/背全身三视图（将脸部强模糊至五官不可识别，保留头部发型）＋唯一正脸特写；不是独立头像和独立三视图。一个叙事镜头只采用一个四宫格，四格都有关键剧情/动作/情绪信息，不用近似姿态凑数。人物设定图不执行剧情宫格切分。

## 开始与接续

用户只要求复盘或整理制作规则时，读取既有记录与规则，提炼可复用流程，不启动当前画布的媒体检查、生成或返工。用户已确认当前项目完成，就保留其结果；新规则用于以后项目，不重新评判或改写本片采用记录。

每次启动 MCP Agent 制作或继续本片，先读 [画布制作规则](references/canvas-production-rules.md)。默认采用“独立人物/场景/道具资产 → 每镜带时间节拍的四宫格 → 切成四图并验收 → 逐镜按需关联 → 分镜行生成视频”。四图是同一条视频的四个关键剧情、动作或情绪状态；按剧情安排各阶段和过渡，不固定每镜 3 秒，也不把多图参考当作严格时间锁帧接口。全部所需图片完成并验收后，才进入本片的视频生成。

封闭室内的固定房间或相连室内空间先读 [固定空间三步流程](references/fixed-space-workflow.md)：第一步采用或生成房型图并确定尺度、方位和连通；第二步从该图建立一个共用空间模型，登记机位坐标、朝向、镜头参数并导出各机位结构图；第三步才按已检查机位制作关键帧、独立切图和视频。已有合格房型、模型及图片直接复用，不能把几张独立生图当作共用模型。户外开放场景直接使用环境与人物参考，不强制该准备流程。跨镜距离问题读 [空间距离与连续性](references/spatial-distance-continuity.md)，区分实际走位与摄影机投影。

先通过 MCP 读取当前画布、项目和可用工具。整片执行读 [MCP 制作与恢复](references/mcp-production.md)；有 runId 时读取持久运行后接续。用户已给的剧本、时长、模型系列、费用授权和声音要求沿用，普通创作细节自主补全。

用镜头的叙事作用、动作难度、参考数量、首尾状态和对白需求选模型。参数以当前渠道能力和实测证据为准；H3 后缀或其他平台的同名模型不能证明本渠道能力。

视频提示词与相邻关键帧先读[视频提示词、关键帧与跨镜衔接](references/video-continuity.md)：前镜末格是连续状态参考，本镜首格继承真实状态并提供新的镜头信息；相邻叙事镜头按[换视角与时长连续性](references/shot-camera-continuity.md)更换真实机位，四张切图真实绑定，按顺序验收采用。确认启用MiniMax H3时先读取官方`h3-prompt-writing`，再读本地`minimax-h3-prompt`适配；其他模型使用各自真实指南。

## 正式制作顺序

从一个剧本接管制作时，先读 [自动化工作流与纠错经验](references/script-to-film-automation.md)，再按 [正式制作流程](references/formal-production-workflow.md) 建立产物和验收记录。模型、字幕、时长、并发与费用授权采用当前用户要求，不套用本片历史默认值：

1. 接收剧本，记录版本、目标时长、画幅与交付规格。
2. 逐场分析剧情，登记角色、场景、道具、台词及连续性。
3. 确定视觉风格与人物外观；封闭场景先完成房型图、共用模型和机位取景再生成，户外按环境参考正常拆镜。
4. 做粗分镜，完整覆盖故事节拍；按用户要求与剧情决定镜头长度，先规划相邻镜头的不同机位及轴线，再为每镜四个关键状态规划连续时间段、固定机位或连续运镜，此时允许修改镜头。
5. 先完成人物、场景、道具独立参考，再直接引用本镜所需资产生成四宫格、切成四张；全部所需图片逐项检查后锁定采用版本。
6. 确定声音路径、说话人和准确台词；对白优先安排在镜头中段，开头留承接、末尾留词尾和反应。先估算或实测读本，台词放不下就调整镜头，不截断或强行加速。需要固定配音时准备实际声线与读本。
7. 把验收通过的图片按各镜实际需求关联到分镜行，完成最终镜头表和带时间的分镜粗剪（Animatic），锁定镜头顺序、采用长度与资产引用。
8. 用代表性高风险镜头验证模型、参考、动作和对白，验证结果可复用。
9. 按锁定镜头逐镜生成、检查、修复，追踪真实任务与素材。
10. 剪辑、调色、声音，按目标帧数完成时间线。按用户当前要求默认不添加字幕或结尾文字；以后明确要求字幕时再制作。
11. 检查整片和导出文件，交付成片及整齐的可编辑画布。

每阶段按必需产物清单执行完整完成门槛；同阶段独立工作可并发，前期草稿可保留修订，但不能据此提前完成或执行依赖未就绪的后续阶段。批量视频等待全部所需图片、真实绑定、声音方案和锁定分镜通过检查。普通单节点功能测试按测试目的运行，不把测试素材当作已通过的正式前期产物。接续时查验已有证据，复用通过的阶段；剧本或资产版本改变后复核受影响的镜头。阶段验收由 Agent 在既有授权下完成，不新增逐步审批。

## 按需调用创作能力

- 剧本拆解、分镜、摄影、表演与提示词：读取已安装 `higgsfield-ai-prompt-skill` 的相关子技能。仅采用与当前任务有关的创作方法；Higgsfield 专有工具、模型参数和语法须转换为衍图实际接口。
- 角色与场景：复用已确认资产版本，每镜记录出现的人物、服装、地点、道具和起止状态。多人物或复杂空间补充站位/视线；单纯景物镜头无需冗长角色卡。
- 局部修图、文字替换、人像/机位/照明调整、透明背景与图层：读 [图片工具与 MCP](references/image-toolbar-tools.md)，先检查当前模型能力，调用真实蒙版/参考和独立图层任务，保留已采用源图并重新检查受影响的连续性。
- 角色声音、准确台词和口型：读 [对白与声音绑定](references/voices-dialogue.md)。遵守运行中的音频模式，不擅自替换原生视频声音。
- 自动化执行、连接恢复和外部技能适配：读 [Agent 接续与技能适配](references/agent-automation.md)。采用本插件真实工具，复用任务与采用版本；页面需要重载时先自主恢复。
- 剪辑、混音、字幕、精确时长：读 [剪辑与交付](references/edit-deliver.md)，需要时加载 `ffmpeg-ops`。需要字幕动画或片头动效时再加载 `remotion-best-practices`；衍图原有时间线可完成的工作直接用 MCP。

## 生成与验收

制作、接续或审计先读 [图片、视频与整片自检](references/self-check-workflow.md)和[AI视觉复查门](references/visual-review-gate.md)。调用真实 `film_self_check` 汇总资源、漏检、过期证据和听审状态；按队列检查实际图片/视频，联动已有分析及修图工具，再写回逐资源、逐格证据。实际有视觉输入的 Agent 或已接入视觉模型完成图片审查，技术解码和审美评分不能替代。新运行默认带自检覆盖合同，未验证、错绑和失败不能放行；该入口不替 Agent 自动产生视觉或声音通过结论。

分镜应能直接执行：叙事目的、人物/场景版本、主动作、机位/运镜、准确台词、参考用途、生成规格与最终采用长度。简单镜头简写，复杂镜头补足空间和时间关系。

先复用画布素材；为单个参考资产生图时明确数量为 1，只有项目确实需要更多独立资产才增加。先验证代表性高风险镜头，再按依赖分批生成；继承首尾状态的镜头使用前镜真实输出，不引用尚未完成的任务。

逐镜检查画面连续性、动作、画幅、真实时长和对白。修改失败部分，保留已经通过的素材；查询超时先查原任务，避免重复计费。检查结果写回持久运行，区分通过、失败和未验证。

每批节点创建完成后，以及交付前，通过 MCP 检查画布，整理受影响区域。按规划、角色/场景参考、视频、音频等用途分区，用均衡网格对齐并留白，例如 16 个同类节点排成 4×4；内容放在对应容器内。保留不相关区域的手工布局，只有用户要求整体整理时才重排整张画布。具体调用和回读见 [MCP 制作与恢复](references/mcp-production.md)。复用已有素材节点，避免重复创建；整理不改变媒体规格或删掉用户内容。

成片长度按时间线和最终帧数控制，不能把模型返回时长相加当作交付时长。最终调用 MCP 的导出和交付核验，检查成片声音、字幕与故事连续性；没有真实成片和所需质量证据时，不能声称整片完成。

技能本身不增加未接通的配音、口型或生成接口。缺少真实能力时报告具体缺口，继续完成其他可执行部分。
