# 以后剧本的自动化制作规范

已整理进整片制作技能 **1.6.5**。核心操作直接写入技能入口，详细执行合同位于 `references/portable-agent-workflow.md`。当前作品按用户已完成的结果保留；这些经验用于后续制作，不再次检查或返工当前画布。

## 执行顺序

每一步先列出完整的必需产物清单。只有清单内全部生成或复用成功、实际资源可读取并逐项自检通过，才算本步完成，才进入下一步。任何缺项、运行中、失败、未检查或不确定项都阻断下一阶段；同一步的多个人物、场景、道具可按授权并发，不能跨阶段抢跑。先修复缺项或失败项，保留合格素材。封闭空间依次验收房型图、同一共享模型和机位；基础资产全部就绪后制作四个关键状态；母图每格和所有独立切图全部验收、真实绑定后生成视频；所有采用镜头检查通过后剪辑，成片验收通过后交付。

支持版本化阶段门（`stageGateVersion=1`）的版本按阶段顺序校验依赖，锁镜阶段自检覆盖全部实际首帧；`pictures:all-ready` 等待所有分镜行的图片验收与关联通过，才放行视频。Agent 必须把每张母图、全部切图与基础资产纳入实际清单，回读后记录真实检查证据，不以只查首帧替代其他图片。2026-10-09 的本地更新已部署阶段门前后端，并在隔离数据环境通过依赖拦截、暂停保护和重启持久状态验证；历史部署使用技能1.6.3、插件0.1.18；当前技能版本以实际目录和读取回执为准。执行时仍读取当前 schema/计划，不能仅根据文档认定另一个安装包已经更新。旧运行不因规则更新自动改指纹；普通手动单节点生成仍可使用，Agent 制作整片必须沿用正式流程和全阶段完成门槛。

1. **接收剧本并拆解。** 提取剧情节拍、人物、场景、道具、准确对白与声音要求。按剧本安排时长和镜头数量，沿用当前配置和授权，不套用旧片的180秒、镜号或人物。
2. **先规划空间。** 封闭室内采用“房型图 → 同一共享模型 → 固定机位和路线 → 图片及视频”。登记门窗、家具、物体尺寸、摄影机位置/朝向/焦段，以及人物起止位置。户外不强制房型或建模。
3. **复用或补齐基础资产。** 已确认人物、场景、道具直接引用；身份、服装、发型、材质、物件数量与承托物保持一致，不重复增加合格资产。
4. **设计四个关键状态。** 四宫格提炼每镜的剧情精华，不把全过程机械切成四段。明确每格的景别、机位、动作、身体朝向、视线和实际位置。前镜末格只传递状态；本镜首格要推进动作。
5. **逐格审核并无边切图。** 检查母图每一格，再检查四张独立切图的内容和切分边界。切图分开排列、标题清楚、放在对应容器内。
6. **真实绑定图片。** 首帧使用本镜独立切图1；其他切图作为各阶段参考，结束图按渠道能力使用。参考按用途、资源和上限去重，逐一核对真实智能@、缩略图、输入顺序、关联和请求。提示词直接写入生成框，采用清楚的【分类标题】。
7. **按模型写视频提示词。** 明确动作顺序、节拍、机位/运镜、人物与道具状态、准确台词、环境声及禁止出现的已知错误。启用MiniMax H3时先读官方技能再应用本地适配；其他模型按其实际能力和指南执行。
8. **候选并发、采用有序。** 依照依赖和当前并发授权提交；仍在运行的任务只查询。每次写画布刷新版本，真实失败重试保留幂等身份和retryOf，已采用素材不被旧任务覆盖。
9. **逐镜自检与返工。** 检查实际资源、关键动作前中后、说话期间、首末态和相邻镜头。声音实际听审，ASR辅助核对原句。发现问题记录具体症状、应有状态、原因证据或原因未知，优化提示词/引用或局部修复，然后复查。
10. **自然剪辑与混音。** 合格片段按剧情进入时间线；连续跨空间的必要过渡确实采用，剧情跳时/跳地点可直接剪切。处理用户要求移除的不合适画面/声音，对白完整、环境声和音乐自然衔接。
11. **检查真实成片并交付。** 完整解码导出文件，核对剧情、节奏、连续性、音画同步、字幕策略和实际时长。保留可编辑项目与采用记录；只有完成规定检查才标记交付。

## 本次经验对应的预防规则

| 以前的问题 | 后续必须落实的规则 |
| --- | --- |
| 门洞突然变大、套出第二道门框 | 使用同一几何布局和对应机位，区分门洞与镜框，按物理开口和透视检查 |
| 人物朝错方向、转场瞬移 | 分开记录身体、头部、视线和走向；路线经过实际出口，按剧情配置过渡 |
| 桌面物件、椅子或收音机消失 | 按数量、位置、材质、承托物和剧情状态登记；正常出画/遮挡与消失分开判断 |
| 换镜后5米变10米 | 用同一世界坐标和测量锚点，机位/焦段变化不改物体间距；不从未标定照片假报米数 |
| 后镜开场复制前镜末格 | 继承状态同时明确本镜新增动作，不完全复刻上一格 |
| 手、工具、镜内动作或人数错误 | 每格、每个高风险动作实际放大/抽帧检查，错误输出不引导后续 |
| 首帧用了母图、@只是文字、漏关联 | 使用独立切图和稳定节点绑定，核对正文智能引用及真实请求，不只看连线 |
| 任务成功就宣布合格、对白没听审 | 可读、内容、声音和正式采用分别记录；缺证据不冒充通过 |
| 超时重复计费、旧结果覆盖新结果 | 查原taskId和采用版本，终态失败在授权内重试，不盲重跑历史脚本 |
| 当前作品已完成仍反复审查 | 仅复盘规则时使用既有记录；保留完成结果，新规则用于新制作 |

## MCP工具如何联动

- `film_self_check`：列出资源、版本、漏检和待验收项，Agent按队列读取实际媒体并判断；工具本身不替代视觉或听审。
- `canvas_read_quality_reports`：读取已有实际报告；报告过期或只覆盖审美时，不充当全片质量通过。
- 图片编辑预检、局部重绘、表情/质感/文字/视角/打光、去背景/图层：按具体错误选择，使用真实输入，保留正确部分，再复查结果。
- 深度、姿态等派生工具：辅助定位几何、动作和遮挡问题；不能证明精确米数或自动给出内容通过。
- 实际抽帧、音轨提取、时间线和ffmpeg：检查视频动作、声音和衔接，修复后重新检查实际导出。

工具以当前MCP目录和模型能力为准；没有提供的入口不能编造。收费调用沿用本次用户授权，其他使用者需要自己的配置和授权。

## 后续使用方式

### 外部 Agent 的阶段接续

MCP 提供读取、生成、检查、登记和剪辑工具；自动推进由连接它的 Agent 持续调用工具完成。安装软件或接通 MCP 不等于已运行完整制作流程。用户要求“写剧本并制作成片”时，Agent 应把成片设为终点，写完剧本后继续拆解、资产、分镜和后续阶段。

先 `skill_search` 查询 `yingce-film-production`，再 `skill_prepare` 准备实际技能版本。短技能入口会返回 `routing` 指向完整技能。长规则超出本轮上下文预算时，读取返回的 `continuationReads`，每次 `skill_read` 带同一个 `preparationId`；补读后用同一 ID 再调用 `skill_prepare` 复核。文件路径以包内参考文件为基准，支持 Markdown 相对链接。页面重载、读取会话过期或版本变化后重新读取；不能假装旧证据已覆盖新规则。

文本、图片或视频任务短提交后按原 `taskId` 等待，任务未完成继续轮询；成功后处理真实产物、登记阶段和检查证据，再继续依赖满足的下一步。`film_wait_task` 的 `continuation` 说明轮询、检查并接续或处理终态失败。阶段验收由 Agent 完成，沿用本次授权；明确暂停、缺少真实模型能力或费用权限时才停在对应原因上。连接客户端如果结束了当前对话，MCP 服务不会自行唤醒它继续制作。

你给剧本后，Agent按这套流程自主完成常规规划、检查和返工，不需要你逐镜指导。已有模型、渠道和费用授权继续沿用；真正缺少必要配置或权限时，只询问缺少的关键项。模型仍可能出错，可靠性来自“检查 → 定位 → 修正 → 复查 → 采用”的闭环。

完整执行规则位于便携插件 `yingce-film-production` 的 `SKILL.md` 及 `references/portable-agent-workflow.md`、`script-to-film-automation.md`、`self-check-workflow.md`、`fixed-space-workflow.md`、`video-continuity.md`。插件文件、Codex技能副本、软件技能库和发布包须核对同一有效版本。磁盘同步不能冒充软件包 API 已更新，未发布的本地规则也不会自动传到别人已下载的旧版本。

## 图片 AI 审查与自动整理（1.6.5）

每张资产、四宫格各格和独立切图必须由实际接收图像的视觉 Agent 或已接入视觉模型审查。对照采用身份图，逐格检查脸、身体连接、额外手/手臂、可见手指、持物、场景、动作及切边，并复查身份和手部。任何 failed 或 uncertain 都阻断该图的下一步，修复或重生后重新审查；技术解码、任务成功、审美分数不能替代。

全部四格通过才原生切一次，四张切图也需分别通过；全片必需图片与绑定就绪才生成视频，视频继续按实际画面与音轨审核。Agent 每批主动整理受影响画布：清楚分区、镜号有序、统一等比卡片、四图2×2、有间隔、来源线完整，并回读实际布局。当前用户已结束的影片保持其结果，新规则用于后续项目。

完整条目见 [AI视觉复查门](../skills/yingce-film-production/references/visual-review-gate.md)，自动排版只按 [布局与单次切图规范](../skills/yingce-film-production/references/canvas-layout-and-split.md)。别人已下载的旧安装包不会自动获得本次本地更新；使用新版技能包并读到1.6.5后才能执行新规则。本次不代表另一台电脑已完成真实全片验收。
