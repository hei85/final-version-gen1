# 本机统一工作区

更新：2026-10-09。

## 原问题

自由画布索引和个人素材列表原先只保存在各浏览器的 IndexedDB。Codex、Edge 是不同的浏览器存储；localhost 与 127.0.0.1 也是不同来源。使用同一便携版服务时，媒体文件已在本机，列表却可能在另一浏览器显示为空。

## 当前保存流程

1. 通过现有会话获取后端用户。便携版沿用现有本机免登录模式。
2. 从同一 `data/open_ai_canvas.db` 的工作区文档读取画布索引、素材、分类、回收站、插件元数据和绘图。
3. 首次接入时导入该浏览器已有记录；旧媒体上传到本机资源目录，稳定资源 ID 代替浏览器专属 Blob 地址。绘图文档和实际渲染图分别保存，保持可编辑。
4. 后续保存携带读取时的版本号；后端事务校验版本。旧窗口的完整快照不能直接覆盖较新的文档。
5. 保留迁移前 IndexedDB 原文、原媒体、首次后端快照及最近十个版本。失败保存保留值和原始基线，恢复连接后重试。只有后端确认后才标记完成。
6. 素材/画布列表在空闲时检查其他窗口更新；正在编辑的画布显示同步入口。连接失败保留当前内容并显示可恢复提示，不转成匿名空工作区。

## 接口和边界

- `GET /api/workspace/documents?key=...`：读取当前用户的文档。
- `GET /api/workspace/documents`：读取当前用户的文档版本清单。
- `PUT /api/workspace/documents`：提交 key、value、baseRevision，版本冲突返回 409。
- Schema 37 增加文档及历史表；不删除原表和资源。文档只允许列出的工作区类型和 drawing 前缀，不接收任意配置/凭据。
- 工作区仍按用户隔离，不把不同账号合并。guest 保持原访客模式。窗口显示偏好等缓存可独立存在。
- 必须连接同一便携实例/数据目录。另一台机器或另一份便携目录不会自动共享。
- 本次不改变模型渠道限制，不提交付费生成，不改 GitHub 发布包。

## 维护要求

- 先备份数据库和待覆盖的程序。不要删除浏览器原始记录或用空列表修复异常。
- 上传本机资源时使用稳定幂等键，迁移失败不得标记成功。
- 增加新的媒体引用字段或工作区文档类型时，同步维护资源引用检查和孤儿资源清理，避免误删共享媒体。
- 重建前端时输出到临时目录，先复制版本化资源，最后替换 index.html；保留旧 hash 文件供仍打开的窗口使用。
- 对两个浏览器和 localhost/127.0.0.1 做实际页面核对；不能把编译成功当成所有功能已验证。

## 本次实际观察

Codex 与 Edge 读取到相同的 17 个画布、480 个素材（382 图片、91 视频、7 音频）。后端重启后仍保留，Edge 换成本机 IP 地址仍可读到 17 个画布。已抽查页面图片实际加载；这不代表逐个媒体或所有生成模型都完成质量检查。
