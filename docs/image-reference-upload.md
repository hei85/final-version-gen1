# 图片参考上传副本

2026-10-13 实测：Axon→CCAPI 的三张3840×2160 PNG参考合计27,368,778字节，在1024输出、自动质量下仍返回400“请求体无效”；同一批参考缩为1280×720、合计3,047,642字节后，Turbo通过同一multipart编辑路径返回一张实际1024×1024 PNG并完整解码。实际请求仍包含三个有序image[]文件部分。Turbo是Axon到上游gpt-image-2的别名。

该结果指向上游参考图像素或体积兼容限制。CCAPI未给出具体拒绝字段和阈值，本次原生替换参考还改变了第三个内联提示标记，不能把这一次结果当作严格单变量实验，也不能称Flare/Sunburst多图已实测通过。

模型能力的image.references新增可选设置：

- `uploadMaxEdge`：多图上传副本最长边。0保留原图；非零为512–4096像素。保持宽高比，不放大小图，用本地Lanczos缩放并编码PNG。
- `uploadMaxTotalBytes`：本地处理后参考图合计字节预算。0不限制；超过预算在提交上游前失败，不自动重发生成。

这些是软件的上传策略，不是对供应商硬性限值的声明。仅显式配置的模型生效；原始资产、引用身份/顺序、提示词和请求输出分辨率保持。当前不处理单图或蒙版编辑，避免改变源图与mask的几何关系。视频和其他协议不应用此策略。普通图片参考可能减少细节，精细局部编辑需使用原始源图和蒙版路径。

后端手写与声明式OpenAI Images路径共用处理。便携包复用已带的FFmpeg，无需接收者另装系统依赖。安全检查、实际任务ID和收费范围继续生效，解码不等于内容审核通过。
